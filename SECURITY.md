# Security Policy

## Supported Versions

Security updates are applied to the latest release on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within `vidopt`, please **do NOT** open a public issue.

Instead, please report it via GitHub's private vulnerability reporting feature:
1. Navigate to the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Provide a detailed summary, steps to reproduce, and potential impact.

We take security issues seriously and will respond promptly with an acknowledgment and mitigation plan.
